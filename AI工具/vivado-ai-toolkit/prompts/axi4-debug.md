# Prompt Library — AXI4 仿真调试

## 入门
**首次运行：**
打开 axi_master_sim 项目，列出仿真文件集，运行 sim_bugs 测试平台以查找并修复 AXI 协议违规。

**运行单个测试平台：**
运行 sim_bugs 中的 tb_axi_master_bug2。显示协议违规并打开波形。

## 调试
**逐个运行所有测试平台：**
依次运行 sim_bugs 中的每个测试平台。每找到一个断言违规，显示波形后等我确认再修复 RTL。

**指定信号波形：**
运行 tb_axi_master_bug3，打开显示写数据通道信号（WVALID、WREADY、WDATA、WLAST、WSTRB）的波形。

**分析基线（正确 DUT）：**
运行 sim_1（带正确 DUT 的基线测试平台），验证它干净通过。

## 修复
**应用修复：**
修复它 — 阅读 RTL 并应用最小改动来解决此协议违规。

**修复后验证：**
重新运行仿真以确认修复有效。显示 PASS 波形。

## 协议学习
**AXI 协议基础：**
解释 AXI4 握手协议 — VALID/READY 信号、通道顺序和 Burst 语义。

**协议检查器：**
AXI 协议检查器（PG101）检查哪些断言？哪些是最常违规的？
