# 提示词库 (Prompt Library)

将以下提示词复制粘贴给 AI 助手即可触发相应任务。

---

## 时序收敛 (Timing Closure)

### 基本时序分析
```
分析当前设计的时序，检查是否有违规路径。目标频率 100MHz，WNS >= 0。
```

### 完整时序收敛（三阶段）
```
对当前设计执行完整的时序收敛流程：
1. 分析布线后时序，分类所有违规路径
2. 生成修复约束 timing_fixes.xdc
3. 重新运行实现并验证

目标：WNS >= 0，无时序违规。
```

### 单次分析
```
打开当前设计，报告时序摘要，列出 WNS 最差的 20 条路径。
```

---

## RTL 代码检查

```
对当前项目运行 RTL Lint 检查，列出所有 WARNING 和 CRITICAL WARNING，并给出修复建议。
```

---

## 设计优化分析

```
分析 opt_design 结果，检查 LUT/FF 利用率、控制集数量，给出优化建议。
```

---

## 多策略对比

```
对比所有实现运行的时序和利用率，给出排名和最佳策略推荐。
```

## 以 chiplab 为例，给出一些能用的提示词

### 时序收敛（100MHz）
```
对 chiplab 设计（loongson 项目）执行时序收敛：
- 目标频率：100MHz
- 约束时钟：clk_pll_i (100MHz), clk_ddr_i (200MHz)
- 如果 WNS < 0，分析违规并生成修复约束
- 最多迭代 3 次
```

### 完整构建 + 时序检查
```
重新构建 chiplab 项目并检查时序：
1. 打开项目 project/loongson.xpr
2. 运行综合 (synth_1)
3. 运行实现 (impl_1)
4. 报告时序摘要
5. 如果 WNS < 0，触发时序收敛流程
```

### 利用率分析
```
分析 chiplab 设计的资源利用率，报告 LUT/FF/BRAM/DSP 使用情况。
```

```
对 <项目名> 设计，目标频率 <XX>MHz，执行时序收敛。器件 <PART>，顶级模块 <TOP>。
```
